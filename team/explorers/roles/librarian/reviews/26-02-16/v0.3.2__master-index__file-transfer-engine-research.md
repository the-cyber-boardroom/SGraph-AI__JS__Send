### Research Documents (in `library/file-transfer-engine/research/`)

| # | Document | Priority | Key Finding |
|---|----------|----------|-------------|
| 01 | `01-s3-multipart-and-presigned-urls.md` | **P1** | Browser-direct multipart via per-part presigned URLs. XHR for upload progress. Lambda never touches file data. |
| 02 | `02-tus-uppy-resumable-js.md` | **P1** | Build from scratch. Borrow patterns from tus (retry backoff, httpStack) and Uppy (S3 plugin, shouldUseMultipart). |
| 03 | `03-browser-storage-apis.md` | **P1** | OPFS for binary chunks (2-7x faster), IndexedDB for metadata. localStorage NOT viable. |
| 04 | `04-s3-constraints-and-costs.md` | **P1** | Egress is 98-99% of cost. Dynamic chunk sizing. Hash-based prefix distribution for rate limits. |
| 05 | `05-compression-algorithms.md` | **P2** | CompressionStream (zero deps) default. fflate (8KB) upgrade. zstd-wasm (300KB) for strong compression. Auto-skip compressed files. |
| 06 | `06-chunked-encryption-patterns.md` | **P1** | Per-chunk AES-256-GCM with counter-derived IVs and AAD binding. 28 bytes overhead per chunk. crypto.subtle across all runtimes. |
| 07 | `07-cloud-providers-comparison.md` | **P2** | R2 is 95x cheaper than S3 for downloads. Single S3 adapter covers 4 of 5 providers. Only Azure needs own adapter. |
| 08 | `08-webrtc-p2p-transfer.md` | **P2** | Phase 3 feature. PeerJS or raw WebRTC. TURN: Cloudflare Realtime ($0.05/GB). Hybrid: WebRTC when both online, S3 fallback. |
| 09 | `09-lambda-streaming-responses.md` | **P3** | 200MB limit but 2 MB/s bandwidth cap — impractical. Presigned URLs bypass Lambda entirely. Not needed. |
| 10 | `10-content-addressable-storage.md` | **P3** | CAS safe for SGraph Send (operates on ciphertext). Phase 1: hash-based keys. Phase 4: FastCDC. Cross-transfer dedup conflicts with zero-knowledge. |

## 4. Key Architecture Decisions

From `comparison-matrix.md`:

| # | Decision | Choice | Rationale |
|---|----------|--------|-----------|
| AD-1 | Upload library | Build from scratch | No library covers >3 of 7 requirements |
| AD-2 | Primary storage | AWS S3 via presigned URLs | Existing infrastructure, S3 adapter covers 4 providers |
| AD-3 | Cost optimization | Cloudflare R2 (config change only) | 95x cheaper egress, same S3 API |
| AD-4 | Compression default | CompressionStream API (gzip) | Zero dependencies, all modern browsers |
| AD-5 | Compression upgrade | fflate (8 KB) → zstd-wasm (300 KB) | Progressive enhancement |
| AD-6 | Browser storage | OPFS (binary) + IndexedDB (metadata) | Best performance + best compatibility |
| AD-7 | Encryption | Per-chunk AES-256-GCM, counter IVs, AAD | Independent chunks, parallel, resumable |
| AD-8 | Transport: upload | Browser → S3 presigned URLs | No payload limits, Lambda only generates URLs |
| AD-9 | Transport: download | S3/CloudFront signed URLs | No payload limits, cheapest path |
| AD-10 | P2P transfer | Phase 3 — WebRTC with S3 fallback | Optimization, not foundation |
| AD-11 | Multi-runtime | Pure JS core, platform adapters injected | Test everywhere, deploy anywhere |
| AD-12 | Transfer state | Transfer manifest as single source of truth | Enables resume, progress, streaming |
