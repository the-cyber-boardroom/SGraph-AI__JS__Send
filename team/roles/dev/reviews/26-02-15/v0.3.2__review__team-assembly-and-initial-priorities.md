- The brief emphasises that the core engine must have zero platform-specific imports. I'll need to be disciplined about adapter boundaries.
- Test strategy: in-memory adapters for unit tests, local FS adapters for integration tests, S3 for end-to-end.
- The CLI is simultaneously a product feature, a testing tool, and a developer tool. It should be designed accordingly.
- Compression research (R8) can run as benchmarks within the test suite.
