## Starting Plan

### Immediate: S3 Research (R1 + R4)

Key questions to document with specific numbers:

**S3 Multipart Upload:**
- API flow: CreateMultipartUpload → UploadPart (x N) → CompleteMultipartUpload
- Part size: minimum 5 MB (except last part), maximum 5 GB
- Maximum parts: 10,000 per upload
- Maximum object size: 5 TB
- Presigned URL per part: yes, supported
- `@aws-sdk/client-s3` has `Upload` class that handles multipart automatically

**S3 Rate Limits:**
- 3,500 PUT/COPY/POST/DELETE per second per prefix
- 5,500 GET/HEAD per second per prefix
- Recommendation: use randomised prefix strategy (e.g., hash-based) for high-throughput chunk uploads

**S3 Transfer Acceleration:**
- Uses CloudFront edge locations
- Additional cost: $0.04/GB (US/EU), $0.08/GB (other regions)
- Typically 50-500% faster for cross-region uploads
- Enabled per-bucket, works with presigned URLs

**Cost Modelling (US East):**
- PUT request: $0.005 per 1,000 requests
- GET request: $0.0004 per 1,000 requests
- Storage: $0.023 per GB/month (Standard), $0.0125 (IA)
- Transfer out: $0.09/GB (first 10 TB/month)
- Comparison needed: Cloudflare R2 ($0 egress), Backblaze B2 ($0.005/GB egress)

### Chunk Size Impact Analysis

| Chunk Size | Chunks for 1 GB | PUT Cost | Notes |
|---|---|---|---|
| 512 KB | 2,048 | $0.01024 | Many small requests, more retries possible |
| 1 MB | 1,024 | $0.00512 | Good for slow connections |
| 2 MB | 512 | $0.00256 | Balanced |
| 4 MB | 256 | $0.00128 | Fewer requests |
| 8 MB | 128 | $0.00064 | Recommended for fast connections |
| 16 MB | 64 | $0.00032 | Risk: large retry cost on failure |
